Q1. What are the assumptions of linear regression?
A1. Okay, so for linear regression to work nicely, we assume a few things. First, there's a linear relationship between the independent and dependent variables. Then, the errors (the differences between what we predict and the actual values) should be normally distributed, have constant variance (homoscedasticity), and be independent of each other. Oh, and the independent variables shouldn't be too highly correlated with each other either!

Q2. When should you use logistic regression instead of linear regression?
A2. You should definitely switch to logistic regression when your dependent variable is categorical, especially binary (like "yes" or "no," "true" or "false," "spam" or "not spam"). Linear regression is for when you're predicting a continuous number, but if you're trying to predict a class or a probability of something happening, logistic regression is your go-to!

Q3. What is the interpretation of coefficients in logistic regression?
A3. This one's a bit trickier than linear regression! In logistic regression, the coefficients represent the change in the log odds of the dependent variable for a one-unit increase in the independent variable, assuming all other variables are held constant. It's not a direct change in probability, but you can exponentiate them to get the odds ratio, which is a bit more intuitive to interpret.

Q4. What is the difference between sigmoid and softmax functions?
A4. The main difference is what they're used for! The sigmoid function is perfect for binary classification problems because it squashes any real value into a range between 0 and 1, giving you a probability. Softmax, on the other hand, is for multi-class classification. It takes a vector of real numbers and normalizes them into a probability distribution, where all the probabilities sum up to 1.

Q5. Why is R-squared not suitable for evaluating logistic regression models?
A5. R-squared isn't great for logistic regression because it's designed to measure how well a linear model explains the variance in a continuous dependent variable. Since logistic regression predicts probabilities of discrete outcomes, and not continuous values, the concept of explaining variance in the same way just doesn't apply. We use other metrics like accuracy, precision, recall, F1-score, and AUC-ROC for logistic regression instead!
